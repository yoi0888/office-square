# OFFICE SQUARE website

GitHub Pagesで公開できる静的サイトです。

## 主要ファイル
- `index.html`：文章・項目の編集
- `style.css`：色・余白・レイアウトの編集
- `script.js`：スクロールアニメーション
- `assets/images/`：ロゴ・施工写真

## 反映内容
- トップのキャッチコピーを「店舗設計・施工」「住宅リフォーム・リノベーション」中心に変更
- 事業内容の順番を奥野様の希望順に変更
- 個人事業主のため、資本金・営業時間・定休日・従業員数・建設業許可番号を削除
- 正式ロゴと施工写真3枚を読み込む構成に変更
